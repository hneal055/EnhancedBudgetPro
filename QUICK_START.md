# PILOTFORGEAI - Quick Start Guide

## 🚀 Start the System
```bash
streamlit run ui_app.py
```
Access at: **http://localhost:8501**

## 📝 Test Workflow
1. Upload `samples/test_script.fdx` on Page 1
2. Click "Analyze Script"
3. Expected: 3 scenes, 3 character arcs (MARCUS, ELIJAH, RAMIREZ)
4. Navigate Pages 2-16 to explore all features

## 🎯 Key Features
- **Pages 1-4:** Core analysis (Story, Finance, Budget, Risk)
- **Pages 5-11:** Production planning (Schedule, Talent, Scenarios)
- **Page 12:** Export Center (Excel, PDF, CSV)
- **Page 13:** AI Producer insights
- **Pages 14-16:** Advanced character analysis (Phase 13.2)
